Detailed Description

Phase 2: Bayesian road status (Notes 6, inference by enumeration).

Network per directed road: Weather -> Status -> {Citizen, Police, Sensor}

  • query : Status S (Open / Congested / Blocked)
  • evidence : the reports, and the weather if it was reported
  • hidden : the weather when it is NOT reported (summed out with the prior)

S is each report's ONLY parent and there are no edges between the reports, so the reports are conditionally independent given S and their likelihoods can simply be multiplied: P(S | w, r1..rn) ∝ P(S | w) · Π_i P(r_i | S) P(w) is the same constant for every value of S, so normalisation removes it.

Prior over the road status, before the reports are used.

If the weather is observed this is the table row P(S | w); otherwise the weather is summed out: P(S) = Σ_w P(w) · P(S | w), which gives Open 0.685, Congested 0.18, Blocked 0.135 (decision 2).

Parameters
modelThe Bayes-net tables.
weatherObserved weather, or None if unknown.
Returns
Status -> probability.

Posterior P(S | weather, reports) ∝ P(S | weather) · Π P(report | S), normalised.

Any subset of sources may be present: a missing source simply contributes no factor.

Parameters
modelThe Bayes-net tables (report CPTs: outer key = TRUE status).
weatherObserved weather, or None to sum it out with the prior.
reportsThe reports for this road.
Returns
Status -> posterior probability.
Note
Example: small N1->N2 (Rain; Blocked, Blocked, Congested) gives O 0.014, C 0.459, B 0.527.
