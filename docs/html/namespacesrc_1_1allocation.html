Detailed Description

Phase 5: responder allocation as a CSP, solved per round (practicum 1: backtracking, MRV, forward checking) with branch and bound on a lexicographic objective.

One round = the incidents that become known at time now (no clairvoyance).

  • Variables : this round's incidents.
  • Domains : responders with the required capability that can reach the incident (unary constraints, filtered first; empty domain -> unhandled).
  • Hard : capability, reachability, one job at a time (queueing: the next job starts when the previous one finishes, at its location).
  • Soft : deadlines. Late help is better than no help, so lateness is a PENALTY, never a reason to fail a branch.
  • Objective : lexicographic (1) Σ priority weight of LATE incidents, (2) Σ (arrival - timestamp).

Because the assignment order also fixes the job order of a shared responder, MRV here affects the QUALITY of the solution, not only the speed (in a classical CSP variable order only changes speed). Without MRV (plain id order) medium t=0 gets worse: R10 does I2 before I3, and the Critical I3 arrives late at 41.6 s (late weight 8 instead of 4).

Note
Limitation: the jobs of one responder are done in the order the search assigns them, and the search order is fixed by MRV, so the CSP is not exhaustive over every job order.

Solve ONE round with backtracking + MRV + forward checking + branch and bound.

Forward checking recomputes every remaining incident's ON-TIME set after each assignment. An empty set does not fail the branch (deadlines are soft): its weight is added to a lower bound, and the branch is pruned when (bound, response time so far) ≥ the best plan found. The bound is valid because extra jobs only make a responder free later and elsewhere, which by the triangle inequality of shortest paths never makes it arrive earlier.
