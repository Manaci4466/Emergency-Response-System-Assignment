Detailed Description

Mutation sweep: does the test suite catch typical bugs in EVERY module?

Usage: python tools/mutation_sweep.py (about 25 seconds)

For each mutant (one small, realistic bug) the project is copied to a temporary folder, the bug is applied to the copy, and the whole test suite runs there. A mutant is CAUGHT ("killed") if at least one test fails; a surviving mutant means a bug of that kind would go unnoticed (a gap in the tests). The real source files are never modified, and no bytecode cache is written (no stale .pyc problems). Each mutation's text must occur exactly once in its file, otherwise the sweep reports an error instead of silently testing nothing.
