Detailed Description

Phase 8: experiments.

Run with python -m src.experiments; writes results/experiments.md.

1-4: sensitivity of the design decisions (tau, unreported roads, unobserved traffic, policy).

5-6: Monte Carlo robustness (prior sampling, Notes 6). The plan is made with EXPECTED costs; here we sample N "true" worlds and replay the FIXED plan in each:

  • each road's true status ~ its Bayes posterior (unreported roads: the prior marginal),
  • each observed road's true traffic level ~ its HMM belief at t = 0 (unobserved roads: Low),
  • a job starts at max(its planned time, the responder's finish time in this world),
  • a route that contains a road that is Blocked in this world fails: the incident is missed, and the responder is stranded, so its later jobs (whose fixed routes start at the incident it never reached) are missed too.

No re-planning: this measures the plan, not the planner.
