Detailed Description

Phase 3: HMM traffic model (Notes 8, forward algorithm / filtering).

Per directed road: X_1 -> X_2 -> ... -> X_n (hidden true traffic level Low/Medium/High), each X_t emitting E_t (the observed level).

Forward algorithm, for every observation:

  1. time elapse : B'(x_t) = Σ_{x_t-1} P(x_t | x_t-1) · B(x_t-1) (skipped for t = 1)
  2. observe : B(x_t) ∝ P(e_t | x_t) · B'(x_t), then normalise

Convention: model.initial = P(X_1), the state that emits observation 1 (no transition before it). Normalising every step keeps the numbers from underflowing; the normalising constants are z_t = P(e_t | e_1..e_t-1), so their product is the likelihood P(e_1..e_n) (chain rule). We use forward (filtering), not Viterbi: we need the distribution of the CURRENT state, not the single most likely history. Works with float and with fractions.Fraction (only +, *, / are used).

Stationary distribution π with π = π · T.

Found by predicting from the initial belief until the belief stops changing. Predicting far ahead converges to π, so far-ahead beliefs lose their road-specific information.
