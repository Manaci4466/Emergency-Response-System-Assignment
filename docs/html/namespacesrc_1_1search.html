Detailed Description

Phase 4b: A* route search (practicum 1), graph search with a closed set. 

f(n) = g(n) + h(n)
g(n) = expected travel time from the start to n along the path found (s)
h(n) = straight-line distance(n, goal) / max_speed(scenario)   (fastest road in THIS scenario)

h is ADMISSIBLE: every road is at least as long as the straight line between its ends, no road is faster than max_speed, and every cost multiplier is ≥ 1, so h never overestimates. h is CONSISTENT: for a road (u, v), cost(u,v) ≥ dist(u,v)/max_speed ≥ h(u) - h(v) (triangle inequality). With a closed set this matters: a consistent h guarantees that the first time a node is popped it has its optimal g, so never re-opening closed nodes is safe. Both properties are checked by tests, not just claimed.

The first premise is a property of the DATA, so it is checked for every scenario: if some road is shorter than the straight line between its ends, h could overestimate, and we fall back to h = 0 (uniform-cost search), which is always optimal.

Best-first graph search with a closed set; A* and UCS differ only in h.

The frontier is a heap of (f, node, g, path), so equal f values are broken alphabetically by node id. The goal test happens when a node is POPPED (not when generated), which makes the result optimal for a consistent h.
